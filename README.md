# MagnOS
A magnet themed operating system. Includes a taskbar with a customizable to-do spot, draggable icons and windows, and a screensaver to keep things moving.

Welcome! Here you can find the code behind MagnOs right now. This operating system was first made using the JamOS guide from Hack Club. Now, it's been expanded to include some magnetism function, which allows it to live up to its name. Swap the magnetic colors to snap windows together, allowing you to create blocks of similar windows that stay in one place. Be careful with the rule of opposites attract, since two windows with the same border colour will repel each other if brought together. MagnOS comes loaded with hidden secrets and quips which you're encouraged to find if you would like. Maybe start by looking at the tab title... The background of the OS is the Windows "Ribbons" screensaver! 

MagZen is an interactive iron-filings visualizer: move your cursor across its canvas to pull the filings in, then click the filings to switch to repulsion. Click again to return to attraction, adjust the force with the strength slider, or pause and reset the filings.

Disclaimer: AI was used relatively minimally for speeding up VS code editing through suggestions, debugging the icon dragging to prevent it from opening, and to add trails to the MagZen filings.
