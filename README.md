# MagnOS
A magnet themed operating system. Includes a taskbar with a customizable to-do spot, draggable icons and windows, and a screensaver to keep things moving.

Welcome! Here you can find the code behind MagnOs right now. This operating system was first made using the JamOS guide from Hack Club. Now, it's been expanded to include some awesome magnetism function, and living up to its name. Swap the magnetic colors to snap windows together, allowing you to create blocks of similar windows that stay in one place. Be careful with the rule of opposites attract, since two windows with the same border colour will repel each other if brought together. The background of the OS is the Windows "Ribbons" screensaver!

Disclaimer: AI was used relatively minimally for speeding up VS code editing through suggestions, as well as for debugging the icon dragging to prevent it from opening after being dragged.
